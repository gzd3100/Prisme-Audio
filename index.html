À propos

Une oreille,

PRISME AUDIO est né d'une conviction simple : un bon son change tout. Pas juste techniquement — profondément. Il change la façon dont une chanson touche, dont un projet convainc, dont une identité s'affirme.

Structure indépendante, regard artistique précis, exigence du détail. Ni agence, ni usine — un partenaire de création sérieux qui s'implique vraiment dans chaque projet.

☁ Pourquoi Cloudinary ?
Cloudinary stocke vos images sur un CDN mondial. Une fois uploadée, l'image a une URL permanente que vous collez dans le site — elle s'affiche pour TOUS les visiteurs, sans aucun backend.
1. Créez un compte gratuit sur cloudinary.com
2. Settings → Upload → Add upload preset → Mode : Unsigned
3. Copiez votre Cloud Name et le Preset name ci-dessus
4. Cliquez "Sauvegarder" puis uploadez vos images ci-dessous
